# ACE Loop OS V2

Daily execution and evidence tracker.

Live app: https://alessandro666777.github.io/ace-loop-os/

Open in Safari on iPhone, then Share → Add to Home Screen.
Entries are stored locally in the browser. Use JSON Export for backups and JSON Import to restore them. There is no cloud synchronization.

The original V2 application files live in `site/`. GitHub Actions deploys only this directory to GitHub Pages on each push to `main`.
